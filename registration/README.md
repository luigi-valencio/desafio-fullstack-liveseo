# Formulário HTML + CSS — commit 2

Abra `index.html` no navegador, sem instalar dependências ou iniciar o backend.

- Campos obrigatórios: Nome, E-mail e Senha.
- Validação HTML nativa de e-mail, nome com conteúdo e senha de 8 a 128 caracteres.
- Layout responsivo e navegação por teclado com foco visível.
- Um pequeno script inline impede qualquer envio, limpa os campos e anuncia a confirmação da demonstração. Não cria contas nem armazena dados. Use senha fictícia.
- Sem JavaScript, o formulário permanece desabilitado para evitar envio acidental.

O CSS está separado em base/tokens, estrutura, apresentação, formulário/estados e adaptação para telas menores.
